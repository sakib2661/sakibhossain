EEE Day 3.0 | Line Following Robot (LFR) Segment

In EEE Day 3.0, I participated in the Line Following Robot (LFR) segment. Competing on the track tested how reliably my robot could read the path and react in real time.

Event Details: EEE Day 3.0 • Segment: Line Following Robot (LFR)

Problem Faced: Line Detection Issue

During the competition, I faced a sensor problem because I used a digital sensor.

My bot could not detect the line properly, making reliable path tracking difficult when surface lighting, contrast, or track conditions shifted.

What I Learned

For a basic LFR bot, a digital sensor is okay, but in competitive robotics, an analog sensor is best.

Digital sensors only give a simple high/low threshold decision, whereas analog readings let a competitive line follower resolve finer position differences and adapt better to real track variations.
